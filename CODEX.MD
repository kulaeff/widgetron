# CODEX

## Назначение файла
- Локальные архитектурные решения и изменения для `widgetron`.

## Принятые решения
- Для MVP сохранения `WidgetCreator` принимает опциональный `onSave`, а кнопка Save размещена внутри `Editor`.
- Во внешний callback уходит только текущий snapshot на момент клика в формате `{ scheme, dataSource, data }`.
- Деталь реализации про внутреннюю кнопку Save и отсутствие внешнего trigger относится только к `CODEX.MD`, а не к `README.md`.
- История версий, отдельный реактивный статус и внешний trigger сохранения в MVP не добавляются.
- В `AI mode` текущий отправленный prompt и его метаданные показываются слева сверху, журнал версий закреплен слева снизу, а строка ввода остается снизу по центру.
- `Design mode` не переустраивается под новый rail-layout и сохраняет прежнюю композицию рабочих панелей.
- `Editor` является бывшим `Home`; переносимая граница редактора находится в `src/app/editor2`.
- Для copy-paste в другой проект нужно переносить `src/app/editor2` вместе с публичными entrypoints `src/widgets/WidgetCreator` и `src/widgets/WidgetRenderer`.
- Default re-export в `src/widgets/*/index.ts` сохраняется как системное исключение для совместимости с внешней системой подключения.
