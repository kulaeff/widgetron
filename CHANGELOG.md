# История изменений

## Без релиза

- Добавлен MVP API сохранения для `WidgetCreator`: callback `onSave` получает текущий snapshot в формате `{ scheme, dataSource, data }`.
- Обновлен AI-режим в `Editor`: текущий запрос вынесен в левый верхний блок, журнал истории закреплен слева снизу, строка ввода оставлена снизу по центру, а кнопка сохранения вынесена левее переключателя режимов.
- Редактор перенесен из `src/pages/Home` в переносимый модуль `src/app/editor2`; публичные `src/widgets/*` оставлены entrypoints для copy-paste подключения.
